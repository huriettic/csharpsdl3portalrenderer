# C# SDL 3 Portal Renderer



A portal renderer made with C# and SDL 3



Windows Visual Studio project.



I don't know how to make it cross platform.



You need SDL3.DLL



uses SDL3-CS package



SDL3 - [https://github.com/libsdl-org/SDL](https://github.com/libsdl-org/SDL)



Put SDL3.DLL with the exe you build.



Put the assets folder with the exe you build.



Move around with WASD keyboard keys and mouse.



The story is you are a big fat sphere and you move around a level.



Can you tell I got the sphere triangle collision working?
